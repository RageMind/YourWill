# YourWill — minimal 2D chunk sandbox

Минимальная версия игры с нуля.

## Что это

Это небольшой 2D canvas-прототип, где мир не создаётся сразу целиком. Чанки генерируются по мере исследования человечками и при просмотре камерой.

## Главное

- Мир состоит из чанков `16 x 16` тайлов.
- Тайл имеет координаты, высоту, биом, ресурсы и список взаимодействий.
- Цветок, яблоко, дерево и камень — отдельные entity-объекты.
- Объекты занимают место на тайле через `occupies`.
- Цветы растут и могут размножаться рядом.
- Яблони периодически создают яблоки рядом с собой.
- Два человечка исследуют мир, открывают новые чанки и собирают/едят яблоки.

## Управление

- Перетаскивание мышью/пальцем — двигать камеру.
- Колесо мыши — приближение/отдаление.
- `+` и `-` — зум.
- `HOME` — вернуться к стартовой области.
- `PAUSE` — остановить симуляцию.
- Клик по тайлу/объекту/человечку — показать JSON entity.

## Важно

Это не большая красивая карта и не картинка. Это минимальная игровая основа:

```text
chunk generation -> tile entities -> object entities -> humans explore -> resources grow/spawn
```

Следующий шаг: улучшить визуал объектов и добавить первые полноценные действия человечков: `walk_to`, `gather`, `eat`, `drink`, `chop`, `build`.
